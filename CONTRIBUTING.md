# Contributing

**Issues are welcome. Code contributions are not accepted.**

pythonbots-core is source-available under a use licence, and every release is delivered to
clients under that licence. Accepting outside code would require contributor agreements and
would change what each order receives; keeping authorship in one place is what makes the
licence simple.

If you found a bug or have a suggestion, open an issue with:

- the version (`/about` prints it, or `pip show pythonbots-core`);
- what you did, what you expected, what happened;
- the startup line, if the problem is about integrity or versions.

Security reports go through the private channel described in [`SECURITY.md`](SECURITY.md).
